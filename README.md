# lemoose6.github.io
This is the source code for the LeMoose website. This website contains all the content created by LeMoose so users can access it for completely free. This is mainly used as a learning project for me, while people can benefit from great content.

## Homepage
This contains everything from LeMoose at a glance. Every important piece of content and information is displayed

### Featured Content
This is a sliding carousel that shows new, popular, or currently relevent content for the user to enjoy. It shows all content from LeMoose that is deemed important.

### Latest News
This shows the most recent post that was not featured, as well as the most recent featured post so users can easily stay up to date on information regarding their LeMoose content.

### Ads
When new big content is being added, it will be displayed at the bottom of the homepage with information about the release.

### Book Scroller
This is an upcoming feature that will show users random selections the library has to offer them

## News Page
This page is split into three important sections that will allow the user to find new information about LeMoose. The sections are featured, judy mudd, and all. 

## Library Page
This is an external page that allows users to browse and interact with the catalog. It also gives users access to important library documents.
